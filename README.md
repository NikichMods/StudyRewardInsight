# Study Reward Insight

Information-only mod for **Graveyard Keeper 1.407** using **BepInEx 5**.

The project aims to make pending Study/Survey rewards easier to evaluate with qualitative hints while preserving the game's exact reward uncertainty. It does not rebalance Study rewards, costs, technologies, recipes, or progression.

Planned installed DLL: `StudyRewardInsight.dll`.

## Status

Early research and design. No stable release is available yet.
